# 惠州中考择校指南网站

## 📊 推荐算法

算法基于三个维度计算匹配度：

1. **中考分数**（权重最高）
   - 高中：550-650+分
   - 中专/职高：400-550分
   - 技工学校：300-450分

2. **兴趣方向**
   - 学术理论 → 高中
   - 技能操作 → 中专/职高
   - 技术实践 → 技工学校

3. **未来规划**
   - 读大学 → 高中
   - 早就业 → 中专/职高/技工

## 📝 使用说明

### 智能筛选步骤
1. 滑动选择中考分数
2. 点击选择兴趣方向
3. 点击选择未来规划
4. 点击"开始分析推荐"
5. 查看推荐结果和理由

### 功能说明
- **分数滑块**：300-700分范围
- **兴趣按钮**：学术理论/技能操作/技术实践
- **规划按钮**：读大学/早就业
- **结果面板**：显示推荐路径和匹配度

## 🎯 适用场景
