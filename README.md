# 惠州中考择校指南

这是一个为惠州中考学生提供择校指导的网站，包含完整的惠州职业学校数据库。

## 功能特点
- 22所惠州职业学校数据库（12所中专/职高 + 10所技工学校）
- 按类型、区域、分数筛选学校
- 详细的学校信息，包括特色专业、就业方向、薪资范围
- 响应式设计，适配手机、平板、电脑

## 访问地址
https://lanstonzhang.github.io/school-guide/

## 技术栈
- HTML5
- CSS3
- JavaScript
- 原生JavaScript，无框架依赖

## 数据来源
基于惠州实际情况构建的学校数据库，涵盖：
- 惠城区、惠阳区、博罗县、惠东县、龙门县、大亚湾区、仲恺高新区
- 工科、医学、商科、艺术、体育、石化、高新等多个领域

## 使用说明
1. 访问网站
2. 点击导航栏"惠州学校"
3. 使用筛选功能查找适合的学校
4. 点击"查看详情"了解学校完整信息
